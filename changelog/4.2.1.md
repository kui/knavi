# Version 4.2.1

Fix missing and duplicated hints on shadow-DOM components such as Reddit's.

- Fix
  - Fix hints not appearing on Reddit video player controls (play, captions,
    playback speed, fullscreen, volume). When an ancestor with
    `overflow: hidden` was checked for pointability, every point it covered
    resolved to an element inside a descendant's shadow tree, which
    `Node.contains()` does not see. The ancestor was judged unpointable and
    every control inside it was dropped. The pointability check now follows
    shadow hosts up to the ancestor.
  - Fix two or more hints appearing at the same spot for one control on pages
    built from shadow-DOM components, such as Reddit. An element inside a
    shadow tree now targets the link or button that hosts it, and a hint for
    an element that only looks clickable (`cursor: pointer`) is dropped when a
    real control, or a nested pointer element, covers exactly the same area.
  - Fix textareas and other editable elements inside a clickable element, such
    as a `role=button` container, getting no hint of their own. They were
    folded into the container's Click hint, so hitting it clicked the
    container instead of focusing the field. They now get an Edit hint.
    Content of a rich text editor still follows the link around it.
