# Version 4.2.1

Fix missing and duplicated hints on shadow-DOM components such as Reddit's,
missing hints on very small or mostly covered links, and GitHub's mermaid
preview failing to render.

- Fix
  - Fix hints not appearing on Reddit video player controls (play, captions,
    playback speed, fullscreen, volume). When an ancestor with
    `overflow: hidden` was checked for pointability, every point it covered
    resolved to an element inside a descendant's shadow tree, which
    `Node.contains()` does not see. The ancestor was judged unpointable and
    every control inside it was dropped. The pointability check now follows
    shadow hosts up to the ancestor.
  - Fix two or more hints appearing at the same spot for one control on pages
    built from shadow-DOM components, such as Reddit. An element inside a
    shadow tree now targets the link or button that hosts it, and a hint for
    an element that only looks clickable (`cursor: pointer`) is dropped when a
    real control, or a nested pointer element, covers exactly the same area.
  - Fix textareas and other editable elements inside a clickable element, such
    as a `role=button` container, getting no hint of their own. They were
    folded into the container's Click hint, so hitting it clicked the
    container instead of focusing the field. They now get an Edit hint.
    Content of a rich text editor still follows the link around it.
  - Fix no hints appearing inside iframes that have no URL of their own, such
    as the Hatena Bookmark button. The page writes their content into a
    src-less `about:blank` frame, which the content script was not injected
    into, so only the "Focus iframe" hint appeared. The content script now
    also runs in `about:blank`, `srcdoc`, `data:` and `blob:` frames.
  - Fix hinting failing right after install or a settings change. Pressing
    the magic key before the settings had loaded showed no hints, and a
    session started while they reloaded ended at the first hint letter, as
    if the magic key had been released.
  - Fix hints no longer appearing until the page was reloaded after the magic
    key was released before the first hints were shown.
  - Fix small links and buttons, 5 to 7 px wide or tall, sometimes getting no
    hint depending on where they were on the page, and links that showed only
    along their right or bottom edge, for example under a fixed banner,
    getting no hint. The visibility check sampled points on a fixed 4 px grid,
    which could miss such an element entirely. It now samples the element's
    centre first, then points spread across the element up to 1 px inside
    each edge.
  - Fix GitHub showing "Unable to render code block" for mermaid files while
    knavi was enabled. Every iframe sent its frame ID to its parent page with
    `postMessage`, and GitHub's mermaid preview fails on unexpected messages.
    Frames are now identified by their position in the frame tree, which each
    frame reports to the background when hinting starts. Only iframes inside
    shadow roots that are cross-origin, and their descendants, still receive
    a message from their parent, once each time hinting starts. In such an
    iframe, the blur key works only after hints have been shown once.
